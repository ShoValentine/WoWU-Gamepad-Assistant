# Presentation artwork

`assets/wowu-logo.png` and `assets/wowu-icon.png` are the replacement artwork supplied by the project owner, copied unchanged from the current Assistant assets. The README uses the originals rather than a redrawn or generated logo.

`assets/how-it-works.svg` is a project-specific explanatory diagram, not a gameplay screenshot. Its labels describe the separation between the gameplay display, Windows Assistant and Moonlight companion device.

The screenshot guide lists the real captures needed for the gallery. No historical screenshot or personal desktop capture has been uploaded as a substitute without being explicitly provided for the gallery.
