# Presentation artwork

`assets/wowu-logo.png` and `assets/wowu-icon.png` are the replacement artwork supplied by the project owner, copied unchanged from the current Assistant assets. The README uses the originals rather than a redrawn or generated logo.

`assets/how-it-works.svg` is a project-specific explanatory diagram, not a gameplay screenshot. Its labels describe the separation between the gameplay display, Windows Assistant and Moonlight companion device.

The screenshots in `screenshots/` were explicitly supplied for this gallery. Seven unique originals are included; the repeated Bags capture is published once. The setup photo and direct captures are unedited. `screenshots/CAPTURES.json` records dimensions, file sizes and hashes. Client names were not explicitly supplied, so the captions do not assert version-specific support.

Warcraft names and game-derived artwork belong to their respective owners. This presentation refresh does not change the project's software licence or redistribute additional game art.
