# Startup message reference

Messages are assigned to tasks, not selected at random. The message stays on that task until startup advances. A stuck quote identifies the stage being attempted. Progress is a smooth stage indicator, not a percentage measurement.

| On-screen message | Task |
| --- | --- |
| Gathering the party | Restore an interrupted game-window session and identify the gameplay monitor |
| Reticulating Splines | Check, install, enable or name the owned virtual display driver |
| Convincing the monitors to cooperate | Restore the previous virtual display position, then configure 1280 x 800 below gameplay |
| Summoning a second screen | Select and remember the gameplay/display setup |
| Doing what Nintendont | Prepare/download the managed Sunshine engine and local credentials |
| Looking for the any key | Match Sunshine's display inventory to the WoWU-owned Windows display |
| Polishing the pixels | Check capture initialization size, offset and available encoder |
| Opening a portal to the sofa | Start the managed Moonlight host and connect the local pairing API |
| Checking the quest log | Find WoWU account saves and remember recognized game installations |
| Applying +10 to couch comfort | Startup finished; open the minimal main window |
| A wild setup issue appeared | Startup encountered an issue; open the main window with its error status |

The underlying task and quote are recorded together with timestamps in %LOCALAPPDATA%/WoWU.GamepadAssistant/startup-stages.log. Exception details are in startup-errors.log; Sunshine diagnostics are in streaming/logs.
